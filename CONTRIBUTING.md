# Contributing

This repository only publishes releases. It does not accept issues or pull requests.

This package is developed in the monorepo [rudderlabs/experimental-swift-monorepo](https://github.com/rudderlabs/experimental-swift-monorepo). Issues and pull requests are welcome there:

- Report a bug or request a feature: [open an issue](https://github.com/rudderlabs/experimental-swift-monorepo/issues/new/choose) and pick `firebase` as the package.
- Change the code: open a pull request on the monorepo. Title it as a Conventional Commit, for example `fix(firebase): handle empty config`. See its [CONTRIBUTING.md](https://github.com/rudderlabs/experimental-swift-monorepo/blob/main/CONTRIBUTING.md).

Maintainers review your change there; it ships in this package's next release.
